# 과제 3: 점프 손맛 다듬기

`PlayerMove.cs`에 8가지 기법을 적용했습니다. 기존 WASD 이동, 왼쪽 Shift 달리기, Space 점프 입력과 2단 점프를 유지합니다. 씬에 저장된 Jump Power 값 8도 그대로 사용합니다.

## Inspector에서 조절하기

GameScene의 Player 오브젝트에서 Player Move 컴포넌트를 선택합니다. 우선 **Jump Count Limit을 1**로 설정해서 기본 점프를 체험하세요. 2이면 남은 공중 점프가 착지 버퍼보다 먼저 실행되므로, 버퍼를 확인하려면 공중 점프를 모두 사용해야 합니다. Play 중 바꾼 값은 종료 시 복원됩니다.

| 기법 | 설정과 초기값 | 손맛이 좋아지는 이유 | 확인 방법 |
| --- | --- | --- | --- |
| 코요테 타임 | Coyote Time = 0.1초 | 발이 턱에서 조금 벗어나도 입력을 받아, 화면을 보고 누른 타이밍과 실제 판정의 차이를 보완합니다. | 턱에서 걸어 나온 직후 Space를 누릅니다. 0으로 바꿔 비교합니다. |
| 점프 버퍼 | Jump Buffer Time = 0.12초 | 착지보다 조금 이른 입력을 기억하여 점프가 무시되는 느낌을 줄입니다. | 착지 직전에 Space를 누릅니다. 착지 시 입력을 소비하고 다음 이동 프레임부터 상승합니다. 너무 일찍 누르면 만료됩니다. |
| 가변 점프 높이 | Jump Cut Multiplier = 0.5 | 키를 놓는 순간 상승 속도를 한 번 줄여, 누르는 시간으로 낮은 점프와 높은 점프를 구분합니다. | Space를 짧게 누른 경우와 정점까지 누른 경우의 높이를 비교합니다. 1이면 높이 조절이 사라집니다. |
| 빠른 낙하 | Gravity = 20, Fall Gravity Multiplier = 2 | 하강 중 중력을 강화해 공중에서 오래 떠 있는 느낌을 줄입니다. | 배율 1과 2에서 정점 이후 착지까지의 시간을 비교합니다. |
| 최대 낙하 속도 | Max Fall Speed = 30 | 긴 낙하에서도 속도가 계속 증가하지 않아 착지 타이밍을 예측하기 쉽습니다. | 높은 곳에서 떨어져 봅니다. 이 값은 속도 상한이며 모든 충돌 관통을 보장해서 막는 설정은 아닙니다. |
| 가속과 감속 | Acceleration = 45, Deceleration = 55 | 속도가 점진적으로 변해 출발·정지에 무게감이 생깁니다. | 지상에서 이동 키를 누르고 놓습니다. 너무 미끄러우면 Deceleration을 높입니다. |
| 공중 제어 | Air Control = 0.35 | 공중 가속과 감속을 약하게 하여 이륙할 때의 관성을 유지하면서 착지 위치를 조금 보정합니다. | 점프 중 반대 방향을 누릅니다. 0은 관성 유지, 1은 지상과 같은 제어입니다. |
| 천장 부딪힘 | 자동 적용 | 천장 충돌 직후 상승 속도를 0으로 만들어 천장에 붙어 있는 시간을 없앱니다. | 낮은 천장 아래에서 점프하여 바로 하강하는지 확인합니다. |

## 함께 수정한 점

- 점프 횟수는 매 착지마다 초기화합니다. 한 번만 점프한 뒤 착지해도 다음 점프 횟수가 정상으로 돌아옵니다.
- 점프에 사용한 입력과 코요테 시간은 즉시 소모합니다. 키를 계속 누르고 있는 것만으로 재점프하지 않습니다.
- 낭떠러지에서 코요테 시간이 끝나면 지상 점프 기회가 소멸합니다. 2단 점프 설정에서는 공중 점프 한 번이 남습니다.
- 버퍼에 저장한 점프 키를 착지 전에 놓았다면 착지 후 짧은 점프가 실행됩니다.
- 수평 속도를 월드 좌표로 저장하여 공중에서 캐릭터를 회전시켜도 이동 방향이 즉시 꺾이지 않습니다.

## 비교 순서

한 번에 값 하나만 바꾸면서 ① 턱 끝 점프 ② 착지 직전 입력 ③ 짧게/길게 누르기 ④ 낙하 ⑤ 출발·정지 ⑥ 공중 방향 전환 ⑦ 천장 충돌을 확인하세요. 같은 구간에서 바꾸기 전과 후를 반복하면 각 기법의 역할을 구분하기 쉽습니다.
